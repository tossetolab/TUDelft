# PGC Building Table to CityJSON Mapping

This document provides a practical one-to-one mapping between attributes generated by PLATEAU GIS Converter (PGC) building tables (e.g., GeoPackage/PostGIS) and their counterparts in CityJSON. The mapping focuses on attributes that are empirically used in GIS workflows, avoiding full i-UR ADE structural replication.

## Mapping Principles

- Core identifiers and frequently queried attributes go to CityJSON attributes
- Urban planning, regulation, and contextual information go to properties.iur
- Numeric values are normalized; units can be stored in metadata if needed
- Attributes not exported by PGC are generally excluded from CityJSON

---

## 1. Identifiers and Basic Information

| PGC Column | Meaning | CityJSON Target |
|-----------|---------|----------------|
| gml_id | CityGML object ID | CityObject.id |
| building_id | Building identifier | attributes.buildingID |
| branch_id | Branch identifier | attributes.branchID |
| part_id | Building part ID | attributes.partID |
| name | Building name | attributes.name |

---

## 2. Building Size and Geometry Metrics

| PGC Column | Unit | CityJSON Target | Notes |
|-----------|------|----------------|-------|
| height | meters | attributes.measuredHeight | CityJSON standard |
| total_floor_area | square meters | attributes.totalFloorArea | Gross floor area |
| site_area | square meters | attributes.siteArea | Parcel or site size |
| footprint_area | square meters | attributes.footprintArea | Building footprint |
| coverage_rate | ratio or percent | attributes.coverageRatio | Building coverage |
| floor_area_rate | ratio or percent | attributes.floorAreaRatio | FAR |
